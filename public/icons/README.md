# Ícones do PWA

## Ícones necessários

Para um PWA completo, você precisa dos seguintes ícones:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Como gerar os ícones

### Opção 1: Usando o icon.svg fornecido

1. Abra o arquivo `icon.svg` em um editor de imagens (como GIMP, Inkscape, ou Figma)
2. Exporte para PNG nos tamanhos listados acima
3. Salve com os nomes corretos nesta pasta

### Opção 2: Usando ferramentas online

1. Acesse: https://www.pwabuilder.com/imageGenerator
2. Faça upload de uma imagem quadrada (mínimo 512x512px)
3. Baixe os ícones gerados
4. Coloque os arquivos PNG nesta pasta

### Opção 3: Usando realfavicongenerator.net

1. Acesse: https://realfavicongenerator.net/
2. Faça upload de uma imagem quadrada (mínimo 512x512px)
3. Configure as opções para PWA/Android
4. Baixe o pacote e extraia os ícones para esta pasta

## Design sugerido

O ícone atual (icon.svg) usa:
- Fundo verde acolhedor (#6f8f87)
- Carrinho de compras em creme/bege (#f7f3ed)
- Coração decorativo (#f4d4a8)

Sinta-se livre para personalizar com:
- Foto da Dona Judith
- Ilustração personalizada
- Logo familiar
- Qualquer imagem que represente carinho e cuidado

## Importante

- Todos os ícones devem ser quadrados
- Formato PNG com fundo sólido (não transparente para Android)
- As cores devem combinar com o tema do app
