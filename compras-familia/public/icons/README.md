# Ícones do PWA

## Como gerar os ícones

Você precisa criar apenas 2 ícones PNG:

- **icon-192.png** (192x192px)
- **icon-512.png** (512x512px)

### Opções para criar:

**1. PWA Builder**
- Acesse: https://www.pwabuilder.com/imageGenerator
- Faça upload de uma imagem quadrada (512x512px)
- Baixe e coloque os arquivos aqui

**2. RealFaviconGenerator**
- Acesse: https://realfavicongenerator.net/
- Configure para Android/PWA
- Extraia os ícones

**3. Imagem sugerida:**
- Fundo verde acolhedor (#6f8f87)
- Ícone de carrinho de compras 🛒
- Ou foto da família/Dona Judith

Enquanto não tiver os ícones personalizados, o app funcionará normalmente, mas não instalará tão bem como PWA.
